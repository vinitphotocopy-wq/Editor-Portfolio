# Contributing to Parv Editor

Thank you for your interest in this project.

## Guidelines

- Keep the website design clean and professional.
- Maintain the existing color theme and typography.
- Ensure mobile responsiveness.
- Avoid adding unnecessary files or dependencies.
- Test changes before publishing.

## Suggestions and Feedback

Suggestions and improvements are welcome.

Please contact the project owner through the official website.
